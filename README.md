# LGBTQ+ Meta-Analysis

Data, code, and reproducibility materials for:

Cornett, K. E. *From Protest to Policy: A Cross-National Meta-Analytic Structural Examination of Policy-Responsive Mobilization in LGBTQ+ Rights Change.*

This repository contains the data and analysis code associated with the study.

## Repository structure

- `data/` – extracted, coded, and processed data
- `code/` – R and Python analysis scripts
- `notebooks/` – Google Colab notebooks
- `outputs/` – tables and figures
- `materials/` – search strategy, coding protocols, and related materials
